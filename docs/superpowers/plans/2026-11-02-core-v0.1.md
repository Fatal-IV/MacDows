# MacDows Core v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.1.0: a notch (clock + media panel) and a dock (running apps) as an extra layer over the untouched Windows taskbar, with settings, fullscreen hiding and signed auto-update.

**Architecture:** One Tauri 2 app with frameless transparent always-on-top windows (`notch`, `dock`, `settings`). Rust modules own Windows integration and emit events; React only renders and sends commands.

**Tech Stack:** Tauri 2, Rust (`windows` crate 0.61), React 19, TypeScript, framer-motion, Bun.

**Spec:** `docs/superpowers/specs/2026-11-02-core-design.md`

## Global Constraints
- Windows 11 only; primary monitor only in v0.1.
- Taskbar is NOT touched in v0.1 (hiding is v0.2).
- Event-driven, no polling loops for window list or media.
- Settings file: `%APPDATA%\MacDows\settings.json`; logs: `%APPDATA%\MacDows\logs`.
- Notch spring: stiffness 380, damping 30. Languages: `tr`, `en`.
- Commits authored only as `Fatal-IV`; no AI attribution lines. License MIT. No code copied from other projects.
- Checks before each commit: `./node_modules/.bin/tsc --noEmit` and `cd src-tauri && cargo test`.

## Review Focus
- Settings file missing, empty or corrupt JSON → app starts with defaults, file is not lost silently.
- Unknown or extra keys in `settings.json` → ignored, not a crash.
- No media session playing → media panel shows the empty state.
- Window with empty title, cloaked/UWP ghost window, or tool window → not listed in the dock.
- Fullscreen detection failure → dock and notch stay hidden (spec default).

## File Structure
- `src-tauri/src/settings.rs` — `Settings`, load/save. 
- `src-tauri/src/fullscreen.rs` — pure decision fn + Win32 probe.
- `src-tauri/src/windows_list.rs` — enumerate user-visible windows, emit `windows-changed`.
- `src-tauri/src/media.rs` — SMTC session, emit `media-changed`, transport commands.
- `src-tauri/src/lib.rs` — builder, window placement, command registration.
- `src/notch/Notch.tsx`, `src/dock/Dock.tsx`, `src/settings/Settings.tsx`, `src/i18n.ts`, `src/bridge.ts` (typed commands/events).
